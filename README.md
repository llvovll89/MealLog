# MealLog

> 오늘 뭐 먹을지 10초 안에 결정하고, 바로 기록하는 식사 의사결정 앱

MealLog는 식사 기록 자체보다 "결정 속도"와 "지속 기록"에 집중한 개인 식단 관리 웹앱입니다.
추천 근거를 노출하고, 기록 데이터를 인사이트로 연결해 행동 변화를 확인할 수 있습니다.

---

## 핵심 기능

### 의사결정형 추천 홈

- 강추천 1순위 + 대체안 제시
- 추천 근거 배지 표시
- 선택 이유 상세 패널(점수 분해 + 최근 섭취 이력)
- 식사 시간대 선택 및 점수 기반 무작위 추천
- 맛 취향 6종, 재료 취향 6종, 조리·식감 4종, 메뉴 형태 3종 복수 선택
- 선택한 취향을 모두 만족하는 메뉴만 추천하고, 후보 부족·없음 안내
- 다시 추천할 때 이미 제시한 메뉴 제외 및 추천 결과로 자동 스크롤
- 알레르기·못 먹는 재료 24종 선택 및 기기 내 설정 저장
- 포함·포함 가능 재료와 정보 미입력 메뉴를 먼저 제외한 뒤 취향 필터와 추천 점수 계산
- 추천 카드에서 바로 기록 저장

### 식사 기록

- 날짜/시간대/메뉴 빠른 입력
- 사진 첨부 및 커스텀 메뉴 등록
- 메뉴 검색, 최근 메뉴, 즐겨찾기
- 기록 수정 및 삭제 후 10초간 실행 취소
- 칼로리 미입력과 0kcal 구분, 기록 당시 칼로리·분류 보존
- 사진 포함 JSON 백업, 검증 후 병합 또는 전체 교체
- 커스텀 메뉴의 맛·재료 태그 등록 및 수정, 백업 시 태그 보존
- 커스텀 메뉴의 포함·포함 가능 재료 입력 및 완료 확인. 수정 시 완료 확인을 해제하고 제외 조건 추천에서 차단
- 제외 설정 백업·복원, 병합 시 제외 재료 합집합 유지. 제외 설정이 없는 이전 백업을 교체 복원해도 현재 제외 설정 유지

### 인사이트 허브

- 주간 리포트/식사 패턴/히스토리/체중·BMI 통합 접근
- KPI 3종: 기록 연속일, 주간 평균 칼로리, 목표 달성률
- KPI 전주 대비 트렌드 + 미니 스파크라인
- KPI 카드 클릭 시 관련 탭 이동
- KPI 지표 정의 툴팁(키보드 포커스 가능)

### 식사 패턴(기록 분포 중심)

- 카테고리 다양성
- 최다 카테고리 비중(편중도)
- 식사 균형 점수(아침/점심/저녁 분포)

## 추천 엔진 v2

추천 점수는 아래 가중치 기반으로 계산합니다.

$$
Score(menu)=0.35\cdot Preference + 0.30\cdot CalorieFit + 0.25\cdot Diversity + 0.10\cdot TimeFit
$$

- Preference: 최근 덜 먹은 카테고리 우선
- CalorieFit: 목표 칼로리 근접도
- Diversity: 최근 14일 중복 페널티
- TimeFit: 아침/점심/저녁 시간대 적합도

엔진은 메뉴 목록뿐 아니라 추천 근거와 세부 점수도 함께 반환합니다.

제외 조건은 점수 감점이 아니라 후보를 제거하는 필터입니다. 저장된 제외 재료와 추가 제외 재료를 합치고, 포함·포함 가능 재료를 대조합니다. 재료 정보가 없거나 입력 완료 확인이 없는 메뉴는 제외 조건을 선택한 추천에 포함하지 않습니다. 후보가 없거나 다시 추천할 후보가 소진되어도 제외 조건을 자동으로 완화하지 않습니다. 저장된 제외 설정이 손상되면 사용자가 다시 확인할 때까지 추천을 중단합니다.

기본 메뉴의 재료 데이터는 일반적인 조리법을 보수적으로 분류한 정보입니다. 실제 제품·매장의 알레르기 안전이나 교차 접촉 여부를 보장하지 않습니다. 먹기 전 제품 표시와 매장의 소스·육수·교차 접촉 정보를 확인해야 합니다. [FDA의 식품 알레르기·표시 안내](https://www.fda.gov/consumers/consumer-updates/have-food-allergies-read-label)를 참고했습니다.

## 인사이트 지표 정의

| 지표 | 정의 | 해석 |
| --- | --- | --- |
| 기록 연속일 | 오늘부터 연속으로 식사 기록을 남긴 일수 | 높을수록 기록 습관이 안정적 |
| 주간 평균 칼로리 | 최근 7일 중 모든 기록에 칼로리를 입력한 날짜의 평균 합계 | 목표 설정 시 목표와의 거리로 해석 |
| 목표 달성률 | 칼로리 입력 완료일 중 목표 칼로리 ±20% 범위 비율 | 높을수록 목표 준수도 우수 |

트렌드 색상 규칙:

- 기록 연속일: 전주 대비 증가면 긍정
- 주간 평균 칼로리: 목표와 거리 감소면 긍정
- 목표 달성률: 전주 대비 상승면 긍정

## 앱 구조

- 상위 탭: 오늘 / 기록 / 인사이트 / 설정
- 인사이트 서브탭: 주간 리포트 / 식사 패턴 / 식사 히스토리 / 체중·BMI
- 상위 탭과 인사이트 서브탭 모두 마지막 선택 상태를 localStorage에 저장

## 데모 시나리오

### 30초 버전

"MealLog는 식단 기록 앱이 아니라 식사 결정을 빠르게 만드는 앱입니다. 오늘 탭에서 강추천 메뉴와 근거를 보고 바로 기록할 수 있고, 인사이트 탭에서 기록 연속일과 목표 달성률 변화를 전주 대비로 확인할 수 있습니다."

### 60초 버전

"MealLog는 메뉴 선택 피로와 기록 중단 문제를 해결하기 위해 의사결정 중심 UX를 적용했습니다. 추천 엔진은 선호도, 칼로리 적합도, 다양성, 시간대 적합도를 점수화해 강추천 메뉴를 제시합니다. 사용자는 추천 이유를 펼쳐 확인하고 즉시 기록하거나 새로운 후보를 추천받을 수 있습니다. 인사이트 허브에서는 기록 연속일, 주간 평균 칼로리, 목표 달성률을 전주 대비 트렌드와 함께 확인해 습관과 목표 준수도를 추적할 수 있습니다."
