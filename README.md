# MealLog

> 오늘 뭐 먹을지 10초 안에 결정하고, 바로 기록하는 식사 의사결정 앱

MealLog는 식사 기록 자체보다 "결정 속도"와 "지속 기록"에 집중한 개인 식단 관리 웹앱입니다.
추천 근거를 노출하고, 기록 데이터를 인사이트로 연결해 행동 변화를 확인할 수 있습니다.

---

## 핵심 기능

### 의사결정형 추천 홈

- 강추천 1순위 + 대체안 제시
- 추천 근거 배지 표시
- 선택 이유 상세 패널(점수 분해 + 최근 섭취 이력)
- 친화형/데이터형 이유 톤 전환
- 빠른 추천 모드(슬롯 애니메이션 단축)
- 추천 카드에서 바로 기록 저장

### 식사 기록

- 날짜/시간대/메뉴 빠른 입력
- 사진 첨부 및 커스텀 메뉴 등록
- 목표 칼로리 대비 진행률 확인

### 인사이트 허브

- 주간 리포트/영양 통계/히스토리/체중/BMI 통합 접근
- KPI 3종: 기록 연속일, 주간 평균 칼로리, 목표 달성률
- KPI 전주 대비 트렌드 + 미니 스파크라인
- KPI 카드 클릭 시 관련 탭 이동
- KPI 지표 정의 툴팁(키보드 포커스 가능)

### 영양 통계(구성 분석 중심)

- 카테고리 다양성
- 최다 카테고리 비중(편중도)
- 식사 균형 점수(아침/점심/저녁 분포)

## 추천 엔진 v2

추천 점수는 아래 가중치 기반으로 계산합니다.

$$
Score(menu)=0.35\cdot Preference + 0.30\cdot CalorieFit + 0.25\cdot Diversity + 0.10\cdot TimeFit
$$

- Preference: 최근 덜 먹은 카테고리 우선
- CalorieFit: 목표 칼로리 근접도
- Diversity: 최근 14일 중복 페널티
- TimeFit: 아침/점심/저녁 시간대 적합도

엔진은 메뉴 목록뿐 아니라 추천 근거와 세부 점수도 함께 반환합니다.

## 인사이트 지표 정의

| 지표 | 정의 | 해석 |
| --- | --- | --- |
| 기록 연속일 | 오늘부터 연속으로 식사 기록을 남긴 일수 | 높을수록 기록 습관이 안정적 |
| 주간 평균 칼로리 | 최근 7일 중 기록일의 평균 섭취 칼로리 | 목표 설정 시 목표와의 거리로 해석 |
| 목표 달성률 | 기록일 중 목표 칼로리 ±20% 범위 비율 | 높을수록 목표 준수도 우수 |

트렌드 색상 규칙:

- 기록 연속일: 전주 대비 증가면 긍정
- 주간 평균 칼로리: 목표와 거리 감소면 긍정
- 목표 달성률: 전주 대비 상승면 긍정

## 기술 스택

- React 19
- TypeScript
- Vite 7
- Tailwind CSS 3
- LocalStorage 기반 데이터 저장

---

## 앱 구조

- 상위 탭: 오늘 / 기록 / 인사이트 / 설정
- 인사이트 서브탭: 주간 리포트 / 영양 통계 / 식사 히스토리 / 체중 추적 / BMI
- 상위 탭과 인사이트 서브탭 모두 마지막 선택 상태를 localStorage에 저장

## 데모 시나리오

### 30초 버전

"MealLog는 식단 기록 앱이 아니라 식사 결정을 빠르게 만드는 앱입니다. 오늘 탭에서 강추천 메뉴와 근거를 보고 바로 기록할 수 있고, 인사이트 탭에서 기록 연속일과 목표 달성률 변화를 전주 대비로 확인할 수 있습니다."

### 60초 버전

"MealLog는 메뉴 선택 피로와 기록 중단 문제를 해결하기 위해 의사결정 중심 UX를 적용했습니다. 추천 엔진은 선호도, 칼로리 적합도, 다양성, 시간대 적합도를 점수화해 강추천 메뉴를 제시합니다. 사용자는 추천 이유를 친화형 또는 데이터형으로 확인하고 즉시 기록할 수 있습니다. 인사이트 허브에서는 기록 연속일, 주간 평균 칼로리, 목표 달성률을 전주 대비 트렌드와 함께 확인해 습관과 목표 준수도를 추적할 수 있습니다."
